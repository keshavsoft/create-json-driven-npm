Official Scaffolder

create-json-driven-npm

Instantly bootstrap clean, type-safe, JSON-driven NPM client architectures without directory sprawl.

$ npm create json-driven-npm ./src/v13

📁 external-api/

Contains api.json (public route allowlist) and api.js (public client facade). Defines the boundary between public API consumers and internal machinery.

📁 internal-working/

Houses the route/ assembly engine (mounting dot-paths in memory) and the execution/ pipeline (where your actual fetch/query logic lives).

📄 source.json

Pure domain specification. Contains endpoint actions, resources, and query metadata. Completely decoupled from transport protocols.

📄 index.js

Strictly single default export re-exporting the client facade with zero namespace collisions.

🎯 The 1-Place Customization Rule

When you scaffold with create-json-driven-npm, you never need to build directory trees. There is only ONE file where custom code is written:

internal-working/execution/index.js

All route parsing, tree nesting, allowlist validation, and public facade bindings are handled automatically by the pre-wired engine.
