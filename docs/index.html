Official Scaffolder

create-json-driven-npm

The code-transporting tool for bootstrapping clean, type-safe, JSON-driven NPM client architectures without directory sprawl.

$ npm create json-driven-npm ./my-api-client

📄 api.json

Public route allowlist contract. Only dot-separated paths declared here are mounted and exposed to callers.

📄 source.json

Pure domain specification. Contains endpoint actions, resources, descriptions, and data payloads completely decoupled from transport protocols.

📁 internal-working/

Houses the route/ assembly engine (mounting dot-paths in memory) and the execution/ pipeline (where your actual fetch/query logic lives).

📄 index.js

Clean composition root importing the JSON contracts and exporting the in-memory callable client instance.

🛡️ Built-in Safety Guard

Prevents accidental overwrites. Refuses to run if target directory contains existing JSON-driven artifacts or unknown non-empty files. Pass --force or -f to override intentionally.

⚡ The Three-Tier Ecosystem

  1. json-driven-npm: The Architectural Source of Truth holding reference templates.
  2. create-json-driven-npm: The Scaffolder that transports the clean skeleton into your project.
  3. create-intellisense: The Type Generator that emits index.d.ts from your JSON contracts.
